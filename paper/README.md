# The report

**Pollard, A. L. (2026). *First Edition: a zero-build publishing platform for student newspapers* [Preprint]. Zenodo. https://doi.org/10.5281/zenodo.23455214**

The report describes the design rationale, architecture, implementation, test strategy,
measured performance and accessibility, the first deployment, and the pedagogical case for
a zero-dependency platform. It measures release 1.0.1 of this repository, archived at
https://doi.org/10.5281/zenodo.23445562 (all versions: https://doi.org/10.5281/zenodo.23445561).

The PDF, its Markdown source and both figures live on the Zenodo record, which is the
canonical copy; they are not duplicated here.
